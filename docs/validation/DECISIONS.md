# Décisions de l’auteur — validation acoustique

Décisions recueillies le 15/10/2026, pendant la reprise de la validation.

- **Avant le calage**, accord pour l’ajout au contrôle qualité concernant un
  silence instrumental occupant toute une journée, après confirmation sur les
  mesures seules. Règle et justification consignées avant application dans
  [le protocole, §8.3](../VALIDATION_PROTOCOLE.md) ; preuves dans la
  [revue QC](qc/REVUE.md). Application uniforme, y compris à Anholt.
- **Après le test indépendant et présentation des résultats**, choix explicite :
  « Conserver v1 ; garder v2 comme étude ». Le profil actif reste donc
  `north-sea-reference-v1`. Les paramètres [C-calé] de v2 restent hors ligne ;
  aucune modification de la transition de propagation ni de la loi des cétacés
  n’est appliquée dans l’œuvre.

Les deux profils échouent au critère de publication pré-enregistré. Le choix du
profil actif n’autorise aucune affirmation de précision ni de compatibilité avec
les cartes publiées. Voir [le rapport complet](../VALIDATION.md).
